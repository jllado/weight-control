# Weight Control lessons

Read relevant entries before planning, implementation, and QA. Current requirements override older lessons; source tasks explain their scope.

- **Preserve recorded workout durations:** Planned targets use five-second steps, but recorded durations accept exact whole seconds. Exercise changes must preserve pre-existing drafts and complete the Review → save → reload journey. Evidence: [task 440](https://todo.devjllado.com/projects/1?task=440).
- **Exercise every guided-workout transition:** Distinguish a recorded skip from advancing without logging; check exercise timers, pause/resume, supersets, Review, and persistence together. Expose imported helpers through Options API component methods before using them in templates. Evidence: [task 437](https://todo.devjllado.com/projects/1?task=437).
- **Keep exercise metadata consistent:** Carry exercise types, units, and muscle selections through the catalog, plan editor, guided session, saved workout, and Coach. Use the current multiple-muscle contract rather than restoring an older single-muscle assumption. Evidence: [task 328](https://todo.devjllado.com/projects/1?task=328), [task 427](https://todo.devjllado.com/projects/1?task=427).
- **Make invalid inputs discoverable:** Show the actionable validation message and scroll to the first invalid field; check long labels and actual controls at narrow mobile widths. Evidence: [task 408](https://todo.devjllado.com/projects/1?task=408), [task 382](https://todo.devjllado.com/projects/1?task=382), [task 384](https://todo.devjllado.com/projects/1?task=384).
- **Separate weekly measurement windows:** Label Saturday–Friday averages separately from dated Friday–Sunday outcomes. Keep archive rows concise, put detail behind navigation/disclosures, and refresh the selected detail along with the list. Preserve the saved snapshot rather than silently recomputing historical values. Evidence: [task 284](https://todo.devjllado.com/projects/1?task=284), [task 452](https://todo.devjllado.com/projects/1?task=452).
- **Keep sleep goals and trends distinct:** Show measured values with negative integer-minute deficits only below a goal; omit zero/positive goal deltas and individual goal-status labels. Keep combined-summary wording and independent trend comparisons; omit value–delta dots. Evidence: [task 446](https://todo.devjllado.com/projects/1?task=446).
- **Keep nutrition summaries concise:** Show single-line 30-day nutrient trends below the longest fasting period. Put plots in Charts → Nutrition; preserve recorded values while omitting the removed target comparisons, seven-day rows, and chart data disclosures. Evidence: [task 450](https://todo.devjllado.com/projects/1?task=450).
- **Verify Coach persistence and publication:** A reflection is complete only when the full accepted payload, including relevant meal/workout summaries and next action, is saved within DTO limits and read back. Changes to GPT instructions or Actions require the documented publication and published-configuration checks. Evidence: [task 409](https://todo.devjllado.com/projects/1?task=409), [task 424](https://todo.devjllado.com/projects/1?task=424).
- **Retain dates when bounding Coach context:** Reduce response size without dropping requested time windows or evidence needed by the reflection. Distinguish missing observations from zero values; never invent measurements from unclear screenshots. Evidence: [task 404](https://todo.devjllado.com/projects/1?task=404), [task 405](https://todo.devjllado.com/projects/1?task=405).
- **Respect completed records and weekly plans:** Use the completed day's intake as authoritative. Evaluate training against the weekly plan, including recovery days, rather than demanding strength work every day. Evidence: [task 442](https://todo.devjllado.com/projects/1?task=442), [task 441](https://todo.devjllado.com/projects/1?task=441).
- **Serialize reminder requests explicitly:** Send the request DTO fields, excluding response-only fields such as timeZone. Exercise schedule save with date/time changes and restore original settings after production acceptance. Evidence: [task 447](https://todo.devjllado.com/projects/1?task=447).
- **Preserve meal details and default scope:** Coach meal writes require a food breakdown and default omitted duration to 30 minutes; task 444 verified source changes but did not publish them. The manual New meal form defaults regular meals to 30 minutes and snacks to five, preserving custom/cleared values and existing/copied durations. Evidence: [task 444](https://todo.devjllado.com/projects/1?task=444), [task 370](https://todo.devjllado.com/projects/1?task=370).
- **Bound day-based adherence:** Per-routine percentages must not exceed 100%. Check individual charts and aggregate summaries together; use distinct eligible days where the metric counts days, with matching numerator/denominator windows. Evidence: [task 349](https://todo.devjllado.com/projects/1?task=349).
